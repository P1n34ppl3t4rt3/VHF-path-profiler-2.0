S/N & Path Loss Breakdown
ParameterValue
Path loss and S/N use the free-space, ground-reflection, and single/multi-obstacle diffraction formulas from your reference field manual, applied automatically depending on how many obstructions the terrain profile shows along the path. Ground dielectric constant sets the reflection term in the ground-wave loss formula, and k-factor sets the effective-earth curvature correction. Elevation data via Open Topo Data (best-available of NED 10m / EU-DEM 25m / ASTER 30m / SRTM 30m for the queried location, falling back to coarser SRTM 90m only if all of those are unreachable) — treat results as planning estimates, not a substitute for a formal coordination survey. Some empirical coefficients were transcribed from a photographed page and are worth cross-checking against your source if precision matters. Satellite imagery © Esri, Maxar, Earthstar Geographics.
